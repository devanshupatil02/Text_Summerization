📚 How It Works

A complete explanation of every component — great for viva preparation.

🔍

Extractive Summarization

Selects the most important sentences directly from the original document using word-frequency scoring. Fast, accurate, no model download needed.

🤖

BART Abstractive

facebook/bart-large-cnn reads the article with its Encoder and generates new summary sentences with its Decoder — just like a human would.

📊

ROUGE Evaluation

Measures word overlap between the generated summary and a human reference. ROUGE-1 (unigrams), ROUGE-2 (bigrams), ROUGE-L (LCS).

📰

CNN/DailyMail Dataset

~300,000 news articles each with human-written highlights. The industry-standard benchmark for summarization research.

Word-Frequency Extractive Algorithm

Extractive summarization selects existing sentences — it does not generate new ones. Think of it as highlighting the most important lines in a textbook.

Step 1 → Split article into sentences (NLTK sent_tokenize) Step 2 → Count word frequencies (skip stopwords like "the", "is", "at") Step 3 → Normalize: divide each count by the max count (range: 0–1) Step 4 → Score each sentence = sum(word_frequencies) ÷ sentence_length Step 5 → Sort sentences by score, pick top-N Step 6 → Return selected sentences in ORIGINAL ORDER

Example

Original (5 sentences)
Scientists discovered a new fish. AI is changing healthcare. The fish was found at 8000m depth. Drug discovery uses ML. Privacy concerns remain.
Extractive (top 2)
Scientists discovered a new fish. The fish was found at 8000m depth.

Advantages & Disadvantages

✅ Advantages
  • Instant — no model download
  • Always factually correct
  • Works offline
  • Easy to understand
❌ Disadvantages
  • No semantic understanding
  • Can be choppy / disconnected
  • Cannot rephrase or paraphrase
  • Just keyword matching

BART — Bidirectional & Auto-Regressive Transformer

BART was created by Facebook AI Research (2020) and fine-tuned specifically on CNN/DailyMail. It has 406 million parameters and a max input of 1024 tokens.

INPUT ARTICLE │ ▼ BartTokenizer [Token IDs: 7234, 5619, 3421 ...] ← text → numbers │ ▼ ┌─────────────────────────────────────────┐ │ BART ENCODER (12 layers) │ │ │ │ Reads ALL tokens SIMULTANEOUSLY │ │ Self-Attention: every word attends to │ │ every other word (bidirectional) │ │ │ │ Output: Contextual Representations │ │ (one rich vector per input token) │ └──────────────────┬──────────────────────┘ │ ▼ ┌─────────────────────────────────────────┐ │ BART DECODER (12 layers) │ │ │ │ Generates ONE token at a time │ │ │ │ Cross-Attention → looks at encoder │ │ Self-Attention → looks at own tokens │ │ Beam Search (4) → explores 4 paths │ │ │ │ Stops at <EOS> or max_length │ └──────────────────┬──────────────────────┘ │ ▼ BartTokenizer (decode) ABSTRACTIVE SUMMARY (new sentences)

Key Concepts

Tokenization

Model doesn't understand English. Tokenizer converts text to numbers. "don't" → ["don", "'t"] (2 tokens). BART's limit is 1024 tokens, not 1024 words.

Attention

Decides which input words to focus on. When generating "researchers", the model attends most to "scientists" in the input.

Chunking (Long Documents)

Articles > 1024 tokens are split into sentence-level chunks. Each chunk is summarized separately, then combined. Limitation: context is lost between chunks.

Hallucination

BART may occasionally generate a fact not in the original. E.g., "Pacific Ocean" in article → "Atlantic Ocean" in summary. Known limitation of all generative models.

ROUGE — Recall-Oriented Understudy for Gisting Evaluation

Measures word overlap between a generated summary and a human reference. It does not measure meaning, fluency, or factual accuracy.

ROUGE-1

Counts matching single words (unigrams).
Reference: "scientists discovered new fish"
Generated: "researchers found new species"
Match: "new" → ROUGE-1 = 1/4 = 0.25

ROUGE-2

Counts matching word pairs (bigrams). Stricter.
Reference bigrams: ("scientists","discovered"), ("discovered","new")...
Generated bigrams: ("researchers","found"), ("found","new")...
Common: none → ROUGE-2 = 0

ROUGE-L

Based on Longest Common Subsequence.
Words don't need to be consecutive.
Captures sentence-level structure similarity.

Precision, Recall, F1

Precision = Matching words ÷ Total words in GENERATED summary "Of what I generated, how much was correct?" Recall = Matching words ÷ Total words in REFERENCE summary "Of what the reference had, how much did I include?" F1 = 2 × (Precision × Recall) ÷ (Precision + Recall) Balanced harmonic mean — we REPORT F1 in papers

Quick Reference for Viva

QuestionAnswer
What is BART?Bidirectional and Auto-Regressive Transformer by Facebook AI (2020). Encoder reads input, Decoder generates summary.
What does the encoder do?Reads ALL tokens simultaneously using bidirectional self-attention. Produces contextual representations.
What does the decoder do?Generates the summary ONE token at a time using cross-attention (encoder) and self-attention (previous tokens).
What is tokenization?Converts text → numbers (token IDs) that the model can process. "don't" = 2 tokens.
What is attention?A mechanism that lets each word decide which other words to focus on. The core of Transformers.
Why BART not T5?facebook/bart-large-cnn is fine-tuned specifically on CNN/DailyMail — perfect for our task. No extra training needed.
What is ROUGE-1?Counts matching single words (unigrams) between generated and reference summary.
What is ROUGE-2?Counts matching word pairs (bigrams). Stricter than ROUGE-1.
What is ROUGE-L?Based on Longest Common Subsequence — non-consecutive word sequence matching.
What is F1?Harmonic mean of Precision and Recall. F1 = 2×P×R/(P+R). We report F1.
What is hallucination?Model generates fluent but factually wrong text. E.g., Pacific → Atlantic. Known LLM limitation.
Why chunking?BART max input = 1024 tokens. Long articles must be split into chunks, summarized, then combined.
Limitation of ROUGE?Measures word overlap only — not semantic meaning, readability, or factual accuracy.
Why pretrained model?Training BART from scratch needs millions of articles and weeks on multiple GPUs. Pretrained = free + instant.
What is beam search?Decoder explores top-4 token sequences at each step, picks the globally best summary. Avoids greedy mistakes.
What is CNN/DailyMail?~300k news articles with human-written highlights. Industry-standard summarization benchmark (v3.0.0).
What is extractive?Picks existing sentences — no new text generated. Fast, accurate, no model needed.
What is abstractive?Generates NEW sentences by understanding meaning. Slower, may hallucinate, more human-like.
What is positional encoding?Transformers process all tokens in parallel — positional encoding tells the model the position of each token.
What is fine-tuning?Taking a pretrained model and training it a little more on a specific task/dataset. We only do inference.
